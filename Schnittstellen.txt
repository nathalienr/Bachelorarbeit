A. Hoch relevant

1. PROFINET / Ethernet Fieldbus (OT-Schnittstelle)
 --> Das Gerät kommuniziert als PROFINET IO Device über zwei Ethernet-Ports.

	Sicherheitsrelevante Testfälle
		Netzwerk-Scan
		Port Scanning
		DCP-Manipulation
		Device Discovery
		Manipulation von PROFINET-Telegrammen
		Flooding / Denial-of-Service
		Netzwerk-Redundanz (MRP)
		IRT-Verhalten unter Last
		Manipulation von Diagnosedaten

2. IoTCore (HTTP) (IT-Schnittstelle)
 --> Das Gerät bietet eine IoTCore-Schnittstelle mit HTTP-Zugriff. HTTPS wird ausdrücklich nicht unterstützt.

	Sicherheitsrelevante Testfälle
		Authentifizierung
		Session Handling
		Web-Security
		Parameter Manipulation
		Information Disclosure
		Rate Limiting
		Directory Traversal
		Input Validation
		Device Enumeration

3. Firmware-Update-Schnittstelle
 --> Firmware-Updates über IoTCore inklusive Blob Upload und Install-Service.

	Sicherheitsrelevante Testfälle
		Unsignierte Firmware
		Manipulierte Firmware
		Downgrade-Angriffe
		Rollback-Angriffe
		Integritätsprüfung
		Unterbrochene Updates
		Upload von Nicht-Firmware-Dateien

4. Debug / Programming Interface
 --> Debug-Interface auf der Leiterplatte.

	Sicherheitsrelevante Testfälle
		Unautorisierte Firmware-Auslese
		Flash-Dump
		EEPROM-Auslese
		Secure Boot Bypass
		Produktionsmodus vs. Servicemodus
		Zugriff auf Debug Pins

5. Netzwerk-Konfiguration

	Über IoTCore verfügbar:
		IP-Adresse
		MAC-Adresse
		Hostname
		Gateway
		DHCP-Informationen

	Sicherheitsrelevante Testfälle
		Änderung von Kommunikationsparametern
		Netzwerk-Rekonfiguration
		Hostname Spoofing
		DHCP-bezogene Angriffe

		Verfügbarkeit

OT-Schnittstellen
1. PROFINET / PROFIsafe
2 × M12 D-codierte Ethernet-Ports
Kommunikation zur SPS/F-PLC
PROFINET für Standarddaten
PROFIsafe für sicherheitsgerichtete Daten (Black-Channel über PROFINET)

OT-Rolle: Steuerung, Prozessdaten, Sicherheitskommunikation.

2. Digitale Ein- und Ausgänge
6 × sichere DI-Ports (6x2 F-DI)
2 × sichere DO-Ports (2x2 F-DO)
Anschluss von Not-Halt, Lichtgitter, Schutztürschaltern, Aktoren usw.

OT-Rolle: Direkte Anbindung von Feldgeräten.

3. Spannungsversorgung
M12 L-codiert
Power In / Power Out (Daisy Chain)
Versorgung von Sensoren und Aktoren

OT-Rolle: Infrastruktur der Anlage.
